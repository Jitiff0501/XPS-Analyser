# XPS Analyser 自动拟合 SOP

> 版本：XPS Analyser v1.2（2026-11）　适用：Thermo Avantage 采集的单色 Al Kα 数据（`.VGD` 或导出表格）
> 本 SOP 说明“⚡ 一键拟合”每一步做什么、依据是什么、什么时候需要人工复核，以及经过验证的准确度。

---

## 1. 适用范围与前提

| 项目 | 要求 / 说明 |
|---|---|
| 激发源 | 单色 Al Kα（hν = 1486.68 eV，自动从 `.VGD` 读取）。其他激发源请在文件或参数中确认 hν。 |
| 数据 | 高分辨谱（每个轨道一个窗口）与全谱（survey，范围 > 300 eV）。强度为 Avantage 的 CPS 原值，程序不平滑、不归一化。 |
| 样品组织 | 一个样品一个文件夹，里面放该样品的全部谱（含全谱）。“打开文件夹”会按文件夹自动分组。 |
| 内置详细模型 | Al2p、Co2p、Cr2p、Cu2p、Fe2p（FeO / Fe₃O₄ / Fe₂O₃·FeOOH 物相）、O1s、C1s。 |
| 按 NIST 数据库建模（v1.1） | 其他有 NIST 单质 / 氧化物 / 氮化物 / 碳化物数据的轨道：Ti2p、Zr3d、Nb3d、Ta4f、Hf4f、Mo3d、Mn2p、Ni2p、Si2p 等（见 3.3b）。其余轨道用通用模型（在数据中找峰，名称取 NIST 最近的化合物）。 |
| 参考数据库 | 随程序发布 NIST XPS Database（SRD 20, v5.0）中 23 种元素（Al、Cr、Fe、Ni、Cu、Co、O、C、Ti、Zr、Nb、Ta、Hf、N、Si、Mo、Mn、Na、K、Ca、Mg、Cl、P）的 17,131 条记录与 943 条双峰间距；Fe2p 用文献整理的数据（Biesinger、Yamashita & Hayes 等）。用户也可导入新的 NIST 导出文件。 |
| 不适用 | 差分荷电严重的绝缘样品、非单色源（有 Kα3,4 卫星）、强烈 X 射线损伤的样品——需人工处理。 |

## 2. 标准流程（操作）

1. **打开文件夹**：选择样品文件夹（或其上一级，自动按子文件夹分成多个样品）。
2. **检查识别结果**：左侧每条谱显示轨道标签；文件名里没有轨道信息的谱会显示“（自动识别）”。全谱会在图上标出各峰归属，右侧列出识别到的元素。识别不对时双击名称重命名。
3. **能量校正（推荐，右侧“手动调整 › 能量校正”）**：
   - 导电的金属 / 合金样品：以金属峰为参考（如 Co⁰ 2p3/2 = 778.2 eV、Cr⁰ 574.3、Cu⁰ 932.6、Al⁰ 72.6）。
   - 绝缘或有污染碳的样品：在 C1s 里选中 **C–C（约 284.5–285 eV 的峰）** 定到 284.8 eV。
   - **注意**：含碳化物的样品，C1s 最高峰可能是 ~283 eV 的金属碳化物，不是 C–C。
   - 未校正也能一键拟合：程序会以金属峰为参照把模型整体平移，并在报告里提示偏差。
4. **选择氧化态**（一键拟合按钮上方，Al2p、Co2p、Cr2p、Cu2p、Fe2p 适用，记住上次选择）：
   - **自动**（默认）：金属态、氧化态都先放进模型，各自与“去掉这一组”的模型比较 BIC 决定是否保留；对 Al、Co、Cr 再拟合一个“仅金属（金属拖尾放宽）”模型，若它同样好或更好，报告“氧化态比例无法由谱唯一确定，范围 0–X%”。
   - **金属 + 氧化**：两者都保留（Cu2p 即使没有卫星信号也加入 Cu²⁺）。
   - **仅金属**：不加氧化峰；金属拖尾自动放宽（T ≤ 0.8、τ ≤ 8 eV），金属峰的 L% 在 0–80% 内拟合，Co 加入金属自身的 +3 / +5 eV 损失峰（2p3/2 与 2p1/2；面积 ≤ 主峰 15%、FWHM ≤ 3.5–4 eV，不让它们变成覆盖整个区域的宽峰）；落在被排除化学态位置上的残差峰和预置重叠峰都不加（否则它们会以别的名字把氧化态“补回来”）。
   - **仅氧化**：不加金属峰（Cu 用对称的 Cu⁺ + Cu²⁺）。
   - 选“仅金属 / 仅氧化”时，程序会与完整的“自动”拟合比较；数据明显支持被排除的化学态（BIC 低 10 以上）时，报告和拟合卡片上都显示 ⚠ 提醒。
   - **样品一致性**（“一键拟合本样品全部谱”后）：按最稳定常见氧化物的标准生成吉布斯自由能（298 K，kJ/mol O₂）：Hf −1088、Al −1055、Zr −1043、Ti −889、Si −856、Ta −764、Mn −726、Nb −706、Cr −705、Mo −533、Fe −503、Co −428、Ni −423、Cu −292。若某元素的氧化态比例比明显更易氧化（相差 > 60 kJ/mol O₂）的元素高 20 个百分点以上，提示其“氧化态”可能是金属线形造成的假象。相差不到 60 的（如 Co 与 Ni、Cr 与 Nb）热力学上分不出先后，不比较。
   - **何时用“仅金属”**：样品在腔内溅射清洁后测量，或有其他证据确认没有氧化。表面暴露过空气的合金，即使体相是金属，通常也有 1–3 nm 的氧化层（XPS 的探测深度约 5–10 nm）。
5. **⚡ 一键拟合本样品全部谱**（右侧顶部；大按钮只拟合当前谱）。拟合后顶部卡片直接显示各化学态比例条、约化 χ² 和残差 RMS，以及**拟合评估**（可靠 / 需检查 / 不可靠 / 未检出，列出每一项依据，见 3.7–3.8）。信号低于检出限的谱不拟合峰，定量时给出上限。
6. **阅读报告**：逐条说明背景选择、模型、每个附加峰的判断依据和警告（蓝 = 重叠峰，紫 = 卫星峰，绿 = 新化学态，橙 = 警告）。按第 4 节复核。
7. **必要时微调**：所有手动项都在“手动调整”下的折叠分区（峰 / 背景 / 能量校正 / 推荐峰位 / 批量），展开状态会被记住。拖动峰顶 / 背景端点、双击峰改约束，然后“局部微调”或“多起点”。
8. **峰颜色**：同一组峰（自旋轨道双峰、多重分裂分量、卫星）自动同色；点峰表中的颜色圆点，或在“编辑峰”对话框里，可以为整组选择其他颜色或自定义颜色（“自动”恢复默认）。导出的图使用相同颜色。
9. **多样品对比**：谱图上方“⧉ 堆叠对比”把所有样品的同一轨道上下错开叠在一起（扣背景归一化 / 归一化 / 原始），可显示拟合包络、分峰和各样品的化学态比例，勾选参与对比的样品，调节间距，并直接导出论文图（PNG / SVG / PDF / TIFF）。
10. **导出与标注**（“导出 › 拟合图…”，或堆叠工具条“导出堆叠图…”）：先出**预览**（就是将要导出的图），在预览上加标注、改峰颜色，确认后导出。单谱图与堆叠对比图各有一套标注，随项目保存。
    - **单位**：字号、线宽、虚线段长 / 间隔、箭头大小都是导出图里的 pt。预览按导出图 1:1 叠加，所见即所得。
    - **加线**：选“加线”，在预览图上点击即在该 BE 处加一条垂直虚线，可连续添加。底端固定在 x 轴；拖线身左右移动，拖上端拉长 / 缩短（长度为坐标轴高度的 %）。默认 0.7 pt、段长 3 pt、间隔 2 pt（段长 0 = 实线）。“主峰位置加线”一次给所有主峰（含 1/2 分量，不含卫星和重叠峰）加上，颜色跟随峰组。
    - **加文字**：选“加文字”，在预览图上点击放置并直接输入，可拖动。默认 8 pt、不加粗，字体 Arial（与坐标轴文字相同）。上标写 `Co^{2+}`，下标写 `2p_{3/2}`（上下标为正文字号的 65%）；“图角标 (a)”放在左上角。
    - **拉箭头**：选“拉箭头”，在预览图上按住从箭尾拖到箭头。拖头 / 尾改变指向，拖中间整体移动。默认线宽 1.5 pt、实心三角箭头（长 7 pt、宽 5 pt，可分别调），可改为开口或无箭头。
    - **参数折叠**：右侧每条标注是一行摘要，点开才显示参数；选中后按 Delete 删除；Esc 退出放置模式。
    - **峰颜色**：右侧“峰颜色”列出各峰组（双峰、多重分裂分量、卫星同色），点击选色，预览立即更新。堆叠对比图里改颜色时，所有样品的同名峰一起改（需勾选堆叠工具条的“分峰”才显示各峰）。
    - **图名**（如 Co2p）放在坐标框内左上角，左对齐（左侧“内容 › 图名”可关）。
    - **堆叠对比图的样品名**（如 HEA、HEN）与左上角图名左对齐，只能上下拖动（左右固定）；默认放在该段曲线之上，双击恢复自动位置。拖过的位置随项目保存，主界面的堆叠图也同步。
    - **图例**：导出图默认不带图例（可在左侧“内容”里打开）；需要标明各峰时用文字和箭头标注，或“峰标注：箭头指向峰”。
    - 主界面的谱图只用于拟合，不显示这些标注。
11. **其他导出**：Excel（全部峰参数、化学态比例、不确定度）、项目文件（可重新打开继续修改，含标注与颜色）。
12. **语言**：右上角“中 / EN”切换界面和报告语言（导出的文件名与峰名保持不变）。

## 3. 自动拟合算法（每一步做什么）

### 3.1 轨道 / 元素识别
- **高分辨谱**：对候选轨道打分——数据峰是否落在该轨道的结合能范围内、是否存在对应的自旋轨道分量（如 Co2p 的 +15.0 eV）、采集窗口是否以该谱线为中心。名称与谱图不符时报告提醒。
- **全谱**：先扣 SNIP 背景，在扣背景后的信号上找峰；**两轮判断**：
  1. 元素“确认”= 最强光电子线存在，且（有 >1 eV 自旋轨道分裂时）两个分量都在；
  2. 其余峰优先归给已确认元素的俄歇峰或次要能级（3p、2s、O2s…），仍无法解释的列为“待确认”。
  这一规则避免了常见误判（如 Co LMM 俄歇 ≈711 eV 误认为 Fe2p、O2s ≈23 eV 误认为 Ta4f）。
- 全谱中**确认**的元素自动加入“样品元素”，用于高分辨谱的重叠峰判断。

### 3.2 背景（任何情况下背景都不高于数据）
| 情况 | 背景 | 依据 |
|---|---|---|
| Shirley 处处不高于数据 | Shirley（端点 5 点平均） | 标准做法 |
| Shirley 会高于数据（≤5σ） | **Smart**：Shirley，但处处 ≤ 平滑数据（v1.2：按能量取约 0.8 eV 宽的平滑窗口，两端窗口逐渐缩小、不外推） | 避免背景切入数据；窗口按能量而不是点数取，弱信号时背景不再贴着单个噪声低谷走 |
| **Fe2p** | **主动 Shirley**：背景 = Shirley 台阶 + t·D(x)，D(x) = (x−x₀) − W·F(x)（F 为 Shirley 台阶形状，两端为 0），斜坡量 t 与峰**一起拟合**；t 的范围由“背景处处 ≤ 数据 + 3σ”算出，显示时再限制 ≤ 数据 | 本底在台阶之外常有线性斜坡。纯 Shirley 会在中段高过数据（斜坡向上）或低于本底（斜坡向下）；前者被 Smart 压到数据上会**吃掉卫星峰**，后者会凭空多出宽“卫星”。两端平坦区太短、太吵，无法单独估计斜坡（实测标准误与斜坡同量级），所以随峰一起拟合 |
| 本底反向（低 BE 端高于高 BE 端 >2σ），或 Shirley 高于数据 >5σ（窗口内有其他谱线） | **自定义点**：在各峰之间、两端平坦区取局部最低点（离峰 ≥1.2×FWHM、≥1.5 eV，避开峰尾），平滑（PCHIP）连接，并限制 ≤ 数据。长空当（>10 eV）分成两段取点时，若最低点落在分割处（说明是斜坡而不是谷底，如卫星侧坡），该点不取 | Shirley 物理假设不成立 |
| 全谱 | **SNIP**（逐级削峰，保留非弹性台阶） | 全谱常用 |

### 3.3 模型与约束（内置文献约束）
| 轨道 | 组分 | 关键约束 |
|---|---|---|
| Al2p | Al⁰（不对称）+ Al³⁺ | Δ 0.44 eV、1/2:3/2 = 0.5 锁定（3.3a）；Al³⁺ FWHM ≤ 2.0 eV |
| Co2p | Co⁰（不对称）+ Co²⁺ + 卫星（~786 / ~802 eV） | 双峰按 3.3a（Co⁰ Δ 14.9–15.1、Co²⁺ Δ 15.1–16.0）；卫星 FWHM 3–6 eV、卫星/主峰 0.3–0.9 |
| Cr2p | Cr⁰（不对称）+ Cr³⁺ (+ Cr⁶⁺) | 双峰按 3.3a（Cr⁰ Δ 9.2–9.4、Cr³⁺ Δ 9.4–9.9）；Cr³⁺ 多重分裂以宽峰近似 |
| Cu2p | Cu⁰/Cu⁺（不对称）(+ Cu²⁺ + 卫星) | 双峰按 3.3a（Cu⁰/Cu⁺ Δ 19.7–20.0、Cu²⁺ Δ 19.8–20.1）；**Cu²⁺ 仅在 940–946 eV 有卫星信号时作为候选**，卫星/主峰 0.4–0.75（CuO，Biesinger）；Cu⁰ 与 Cu₂O 的 2p3/2 不可分，需 Cu LMM（α′） |
| Fe2p | Fe⁰（不对称）+ 一个氧化物**物相**：FeO / Fe₃O₄ / Fe₂O₃·FeOOH（见 3.5 第 6 条） | 双峰按 3.3a（Fe⁰ Δ 13.0–13.25；氧化物 Δ 13.3–13.9，相对 2p3/2 包络重心）；每个物相：2p3/2 = 主线 + 高 BE 多重分裂线（间距 1.0–2.2 eV、面积比 0.3–0.8、宽度比 1.0–1.4），2p1/2 = 一个宽峰（Coster–Kronig 展宽，宽度为主线的 1.2–2.5 倍），卫星随主线移动。FeO 主线 708.7–709.9、卫星 +5.4–7.0 eV（面积比 0.2–1.0）；Fe₃O₄ 主线 709.6–710.6、卫星宽而弱（+5.5–8.8 eV，面积比 ≤0.2）；Fe₂O₃ 主线 710.1–711.3、卫星 +7.6–9.2 eV（面积比 0.12–0.7） |
| O1s | 晶格 O / 缺陷·羟基 / C–O·吸附水 | 位置窗口 ±0.6–0.9 eV |
| C1s | (金属碳化物) + C–C / C–O / C=O·O–C=O | 282–283.7 eV 有明显信号才加碳化物 |

- **峰位范围**：模板峰 ±1 eV（保证各化学态不互换位置），手动加峰 ±2 eV。
- **FWHM 默认 1–3 eV**（卫星 1–8 eV；金属 Al⁰ 允许 0.6 eV；CuO 主峰允许 3.5 eV）。

### 3.3b 没有内置模型的轨道：按 NIST 数据库建模（v1.1）
1. **候选化学态**：NIST 中本元素的单质、氧化物、氢氧化物、氮化物、碳化物（同一化学式至少 3 条记录），主线中位数落在数据窗口内的。金属上的氧化膜（NIST 写作 Al2O3/Al 等）按 `xps_formula` 中 * 标出的组分归类。
2. **合并分不开的态**：中位数相差 < 0.8 eV 的化合物在常规分辨率下分不开，合并为一个候选（名称写出不同类别，如 TiN/TiO）。与单质相差 < 0.8 eV 的化合物（如 MoN 228.4 与 Mo 228.0）：样品里有对应元素（氮化物 N、碳化物 C）时与单质合并并写明（Mo0/MoN），否则不列为候选——否则对称的“化合物”峰会顶替金属峰。
3. **峰位与峰形**：峰位以 NIST 中位数为起点，限制在四分位范围放宽 0.3 eV（最多 ±0.9 eV）；p/d/f 轨道用自旋轨道双峰（3.3a 的金属 / 化合物范围）；单质用不对称峰。该位置几乎没有信号（< 峰高 3%）的候选不加。
4. **取舍**：全部候选一起拟合后，每一轮去掉“去掉后 BIC 改善最多”的一个，直到去掉任何一个都会使 BIC 变差（逐步剔除，与候选顺序无关）。报告列出候选和保留的化学态。
5. **氧化态选择**同样适用（仅金属 / 仅氧化 / 自动），“自动”时同样对比“仅金属”模型、参与样品一致性检查。
6. **局限**：真实化学态偏离文献分布（固溶、混合氧化物、强荷电）时，候选峰位范围可能不够，需要人工复核；Ni2p、Mn2p 的多重分裂与卫星没有专门的包络模型（NiO 与 Ni(OH)₂ 的区分不可靠，见 5.4）。

### 3.3c 碱金属 / 碱土金属（K、Ca、Mg、Na…）、噪声峰与深度剖析（v1.2）
来自一组极化（腐蚀）后样品的深度剖析数据（C1s、Ca2p、Cl2p、K2p、Mg1s，刻蚀 0 / 135 / 270 s）与独立人工拟合的对照：
1. **盐作为候选**：这些元素在腐蚀、沉积、生物矿化表面上以碳酸盐、氯化物、磷酸盐等形式存在。NIST 中本元素的简单无机盐（化学式只含本元素、H、O 和一种阴离子元素 C / F / Cl / Br / I / P / S / N）在样品含该阴离子元素时作为候选（O 总是允许）。盐的化学位移小、文献值分散主要来自荷电参考，峰位范围放宽到 ±1.2 eV，但相邻候选只到两者中点（名称不会随拟合在 CaCO₃ / CaCl₂ 之间乱跳）。氧化物离单质很近（CaO 与 Ca 差 0.75 eV）时与相邻化合物合并，而不是丢掉。
2. **金属态要有峰**：这些元素的金属态在空气中几乎不存在，只在溅射后的合金等少数情况出现。只有平滑后的信号在单质位置 ±0.6 eV 内有局部极大（高于 3σ 噪声、不低于最高峰的 25%）时才加金属态——否则金属峰会去“补”化合物峰的展宽（v1.1 在 Ca2p 上出现 10–23% 的“Ca0”，在 Mg1s 上把 Mg²⁺ 当成平移了 0.9 eV 的金属）。
3. **能量标尺**：同一样品（深度剖析时同一层）有 C1s 且 C–C 主峰在 284.8 ± 0.5 eV 时，认为能量标尺可信，不再按单质峰整体平移模型。参考库里只有单质、峰又比单质高 0.6 eV 以上时，峰名写作 X(ox)（如 Mg(ox)），不硬说是金属。
4. **噪声峰**：数据驱动加入的峰（通用模型、NIST 候选、残差峰）拟合后若单峰匹配滤波 S/N（峰高 / σ × √(0.75 × FWHM / 步长)）< 4（与检出限同一口径），视为计数波动删去并重拟合；通用模型找峰时同样先用这个标准过滤。内置模型的标准组分不受影响。
5. **自旋轨道分量顺序**：通用模型找峰时若先找到的峰其实是另一个峰的 1/2 分量（背景扣歪时 1/2 可能更高，如 C1s 损失背景上的 K2p），改用低 BE 的那个作为 3/2。
6. **C1s 低结合能组分**：样品里没有能形成碳化物的元素（Ti、Zr、Cr、Si、Fe…）时，282–284 eV 的组分叫“C low-BE (sp2/sputter)”（Ar⁺ 溅射造成的无序 / sp² 碳等），范围 283.0–284.3 eV，不再叫碳化物、也不再卡在 283.6 eV 上限。
7. **深度剖析**：`.VGD` 里第二个轴为刻蚀时间时读出（如 0 / 135.19 / 270.38 s），谱名写作 “C1s Scan [135 s]”；定量时每一层单独作为一行（“样品 · 135 s”），不再只用第一层。
8. **定量缺灵敏度因子**：灵敏度因子表里没有的轨道（如 Mg1s）在定量表里标出“缺灵敏度因子”，可在定量窗口填写（以前是静默略过）。
9. **局限**：弱信号（S/N < 10）落在别的谱线的陡峭损失背景上时（如 0 s 层 C1s 之后的 K2p），面积对背景选择很敏感，自动结果只能作参考，需人工复核背景。

### 3.3a 自旋轨道双峰（1/2 与 3/2）的文献约束
所有双峰（一键拟合的模型、残差中新加的化学态、手动“添加双峰”、模板）都使用同一张表 `core.SPIN_ORBIT`，金属态（不对称峰或名称如 Fe0）与化合物分开：
- **ΔE**：在范围内拟合（常用值作起点）。依据 NIST XPS Database (SRD 20) 的分布、Thermo Fisher “XPS Simplified” 元素页与 Biesinger 等（2010、2011）的 2p 数据。
- **面积比**：理论 (2j+1) 比 p 0.5、d 0.667、f 0.75，允许约 ±0.05（背景、Coster–Kronig 效应）；Ti、V 的 2p 实测常偏低，下限放宽。
- **FWHM 倍率**：3d 过渡金属的 2p1/2 因 Coster–Kronig 衰变比 2p3/2 宽（Ti、V 最明显），3d / 4f 分量基本等宽。Fe、Co、Ni 金属的 L₂ 能级自然宽度约为 L₃ 的 2 倍（L₂–L₃M₄₅ Coster–Kronig；Campbell & Papp, *At. Data Nucl. Data Tables* 77 (2001) 1），叠加仪器展宽后 FWHM 比约 1.4–1.7，面积比实测常略低于 0.5——范围按此设定。最初把 Co 金属限制在 1.0–1.4 时，模型被迫用“Co²⁺”去补 2p1/2 附近的强度（用户的全金属样品暴露了这个问题）。

### 3.4 不对称拖尾（金属态）
- 金属态（Al⁰、Co⁰、Cr⁰、Cu⁰…）用“GL + 高 BE 侧指数拖尾”峰型，面积为真实面积（可直接定量）；氧化物 / 化合物保持对称 GL。
- **两步拟合**：先把拖尾固定在典型值（T=0.25、τ=1.2 eV）让各组分定位，再在常见范围内放开（T 0.05–0.45、τ 0.5–2 eV）。
  *原因*：过长的拖尾会“吃掉”相邻氧化物 / 高价态的信号（验证中曾使 Cr³⁺ 少算 15%、Cr⁶⁺ 漏检）。

### 3.5 重叠峰 / 卫星峰 / 新化学态的判断
按以下顺序，先“预置”，再看残差：

1. **预置重叠峰**：样品中其他元素的谱线若落在当前窗口内（俄歇峰按 BE = hν − KE 换算），拟合前就加入为“重叠峰”（不计入定量）。双峰能级（如 Cu3p 75.1 / 77.4 eV）按锁定间距加入，远离主峰的分量把整对峰锚定。与本谱主峰相距 <1 eV、无法区分的（如 Al2p 窗口里的 Cr3s 与 Al³⁺）不加，只在报告中警告。拟合后面积 <1% 的预置峰自动去掉。谱未做能量校正时，以金属峰检测到的整体偏移同样施加到这些谱线上（否则重叠峰会放在错误的位置）。
2. **化学态测试**：本元素常见、且**能分辨**的其他化学态（与已有组分相距 ≥ max(1.5 eV, 0.8×FWHM)，如 Cr⁶⁺）逐个试加，BIC 明显下降（>10）且面积 ≥2% 才保留。分不开的态（Cr(OH)₃/Cr₂O₃、Al(OH)₃/Al₂O₃、Co³⁺/Co²⁺）不拟合，只提示。
3. **候选组分**：需要卫星佐证的价态（如 Cu²⁺）作为候选，与“不含它”的模型比较 BIC；BIC 更好但 ≥2 个参数卡在约束边界（说明在填补背景或其他信号）时也不保留。
4. **残差检查**：拟合后在残差里找显著峰（>4σ、面积 ≥1.5%），依次判断：
   - **重叠峰**：与同样品其他元素的俄歇峰（±1.5 eV）或能级（±0.9 eV）吻合；已识别的俄歇峰 ±5 eV 内的残差归同一来源（俄歇峰很宽）；
   - **卫星峰**：位于本元素主峰高 BE 侧的卫星区间（Co 2.5–12、Cu 6–12、Ni 5–8、Fe 5–9、Mn 4.5–7、C 5.5–7.5 eV…），且只归给能带卫星的态（如 Cu 只归 Cu²⁺）；
   - **新化学态**：落在本元素常见态的范围内；
   - **无法归属**：加为未知峰（不计入定量），报告提示人工确认。
   每加一个峰都要求 BIC 显著下降（>6），否则撤回。
5. **Co2p 模型对比**：金属 Co 在主峰 +3~+5 eV 有固有损失结构，与 Co²⁺ 卫星区重叠。程序同时拟合 A（肩峰全归 Co²⁺）与 B（加入 Co⁰ 损失峰），**报告 Co²⁺ 范围**，默认显示 BIC 更好的模型。
6. **Fe2p 物相判断**（FeO、Fe₃O₄、Fe₂O₃/FeOOH 的 2p3/2 只差 1–1.5 eV，主要靠卫星区分）：
   - 依次拟合三个**单相**模型（各含 Fe⁰，若有），先粗拟合再各自完整收敛（主动 Shirley 的斜坡需要充分迭代，否则正确的模型也可能没拟合好而落选），按 BIC 选**主物相**，默认显示；
   - 再拟合两相模型（Fe₃O₄ + Fe₂O₃、FeO + Fe₃O₄）。两相模型多出一整套峰，在峰形只是近似时**几乎总能拟合得更好**（模拟中纯 Fe₂O₃ 加第二相，χ² 也能降一半），不能据此确认混合，只用来给出 **Fe²⁺ 比例的范围**；
   - 报告中的“解读”给出：物相、推算的 Fe²⁺:Fe³⁺（FeO 全为 Fe²⁺，Fe₃O₄ 为 1:2，Fe₂O₃ 全为 Fe³⁺）、若为混合时的 Fe²⁺ 范围、金属 Fe⁰ 占比；
   - Fe₂O₃ 与 FeOOH 的 Fe2p 几乎相同，需结合 O1s 中 ~531.2 eV 的 OH 组分判断；
   - 物相判断依赖峰位，**务必先做能量校正**（±0.2 eV 内）。
7. **金属 / 氧化的歧义检查**（自动模式，Al、Co、Cr）：金属峰的真实拖尾可能比默认上限（T ≤ 0.45）更长，这时“金属 + 氧化态”与“长拖尾的纯金属”都能解释主峰高 BE 侧的肩。程序另拟合一个仅金属（T ≤ 0.8、τ ≤ 3.5 eV；Co 含损失峰）模型：BIC 不比默认模型差 10 以上时，报告氧化态比例范围 0–X%。验证：在真实含氧化态（17–69%）的模拟谱上 18 次都没有误报（仅金属模型的 ΔBIC 中位数 +326 至 +754）。
8. **多起点**：最后从 6 组随机起点重拟合，取最优。

### 3.6 质量检查（自动给出警告）
- 背景是否高于数据；参数是否卡在约束边界（峰表 ⚠）；双峰面积比是否偏离理论值 >15%；残差 RMS / 峰高；每个参数的 ±1σ 不确定度（峰表悬停查看）。

### 3.7 检出限：这条谱里有没有该元素的信号
- **方法**（匹配滤波）：在该元素主线常见的 BE 区间（金属到最高价态，两侧各放宽 1.5 eV）内逐点、按三种峰宽（FWHM 0.9 / 1.6 / 2.8 eV）拟合“高斯峰 + 局部直线背景”，S/N = 高斯幅度 / 其标准误差；噪声 σ 由二阶差分的中位绝对偏差估计（不受峰影响）。
- **阈值**：纯噪声谱上因为在多个位置、峰宽上搜索，S/N 的 99% 分位约 3.1–3.7（平坦 / 斜坡 / 台阶背景各 150 次模拟），所以 **S/N < 4 = 未检出**（误判约 1%），**4–10 = 弱信号**（已检出但低于定量限），**≥ 10 = 可定量**（IUPAC 定量限 10σ 的惯例）。
- **校准**（Co2p，本底 2×10⁴ counts）：峰高为单点噪声的 0、0.4 倍时 12/12 未检出；1.1 倍时 10/12 未检出；2 倍时 11/12 判为弱信号；4 倍时多为弱信号；≥ 10 倍时 12/12 可定量。
- **未检出时**：一键拟合不拟合峰（报告里写明 S/N），评估显示“未检出”；**定量**里该轨道不计面积，显示“< x（未检出）”——x 为检出限对应的原子 % 上限（区间中点一个 FWHM 1.6 eV、S/N = 4 的峰）。
- **局限**：只看主线区间。若区间内有其他元素的谱线（重叠），会被当作信号；元素是否存在仍应结合全谱识别。
- **v1.1 核对**：28 个轨道的主线区间与 NIST 中单质 / 二元化合物的结合能分布（5–95%）比较，全部落在检测窗口（主线区间两侧各 1.5 eV）内；个别轨道的 NIST 分布超出用于轨道识别的区间（含氟化物、磷酸盐等，如 Al2p 到 76.7、C1s 到 292.3、P2p 到 135.6 eV），但扩大识别区间会增加相邻轨道的误认（如 Al2p 与 Cu3p），所以识别区间保持不变。

### 3.8 拟合评估（可靠 / 需检查 / 不可靠 / 未检出）
一键拟合后在“拟合”卡片里显示，左侧谱列表的圆点颜色相同（绿 可靠、橙 需检查、红 不可靠、空心灰 未检出），Excel 导出有“Assessment”表。
- **检查项**：
  - 信号 S/N（见 3.7）；拟合是否收敛。
  - 残差：与噪声比，也与峰高比。残差 RMS ≤ 2 × 噪声（相邻点常相关，噪声估计略偏低）或 ≤ 峰高的 1.2%（信号很强时线形的细微差异会超过噪声）视为正常；≤ 峰高的 3% 或 ≤ 4 × 噪声为“需注意”；更大为严重。残差里还有 >4σ、面积 ≥1.5% 的未拟合信号为“需注意”。
  - 背景高于数据（超过 5σ 为严重）；主峰的峰位或 FWHM 上限卡在约束边界（需注意；FWHM 在下限只说明峰很窄，卫星 / 损失峰卡边界影响小，只作说明）；自旋轨道参数不在文献范围或面积比偏离理论值（需注意；到达文献范围边界只说明约束在起作用）。
  - 无法归属的峰（需注意）；按选择未加入、但数据显示存在的化学态（严重）；样品一致性（需注意）；氧化态比例不唯一（需注意，给出范围）；化学态比例 1σ 不确定度 > ±8 个百分点（需注意）。
- **结论**：有严重问题或 ≥ 4 项需注意 → 不可靠；有需注意 → 需检查；否则 → 可靠。

## 4. 人工复核清单

| 检查 | 通过标准 | 不通过时 |
|---|---|---|
| 背景 | 在峰两侧平坦区贴近数据，任何地方不高于数据 | 拖动背景端点，或改用自定义点背景 |
| 残差 | 无明显结构（< ±3σ 的随机噪声） | 看报告中“无法归属”的峰；补充“样品中其他元素”后重跑 |
| 双峰 | ΔE 与文献一致（±0.1 eV）；1/2:3/2 接近 0.5 / 0.667 / 0.75 | 比值明显偏低多为 1/2 分量处背景或重叠问题 → 只用 3/2 定量 |
| 卡边界（⚠） | 没有，或有合理解释 | 放宽 / 收紧该参数范围后“局部微调” |
| 能量校正 | 金属峰或 C–C 位于参考值 ±0.2 eV | 做校正后重新一键拟合 |
| 卫星 / 重叠 | 归类符合化学常识（如 Cu⁰ 不应有卫星） | 双击峰修改“类型”（主峰 / 卫星 / 未知重叠） |
| 不确定度 | 关键组分面积相对误差 < 10% | 信噪比不足时只报告趋势，不报告精确比例 |
| Fe 物相 | 主物相与卫星特征一致：FeO 在 ~715.5 eV、Fe₂O₃ 在 ~719 eV 有清楚卫星，Fe₃O₄ 只有平台 | 先确认能量校正；需要混合模型时套用模板“Fe2p: Fe₃O₄ + Fe₂O₃”；Fe₂O₃ / FeOOH 结合 O1s 的 OH 判断 |

### 4a 拟合不理想时：逐步放宽约束
默认约束（L% 固定 30%、FWHM 1–3 eV、化合物对称、双峰按文献范围、峰位窗口…）偏保守，目的是让一键拟合稳定、各化学态不互相“抢”面积。残差仍有结构时，**不要一次全部放开**：这些参数高度相关，全放开后几乎总能把残差压下去，但化学态比例会失去意义。右侧拟合卡片中的“逐步放宽约束”按风险从低到高逐级放开：

| 级 | 放开的约束 | 风险 | 理由 |
|---|---|---|---|
| 1 | Lorentzian 比例 | 低 | 仪器展宽（高斯）与寿命展宽（洛伦兹）的比例因谱仪和化学态而异，放开它物理上最没有争议 |
| 2 | 背景斜坡 | 低 | 本底在 Shirley 台阶之外常有线性斜坡；随峰拟合，背景仍不高于数据 |
| 3 | FWHM 范围 | 中 | 默认 1–3 eV 适合多数单色 Al Kα 高分辨谱；窄的金属峰或宽的多重分裂峰可能需要更宽的范围 |
| 4 | 金属拖尾 | 中 | 金属的拖尾长度因元素和导电电子而异；过长的拖尾会吃掉相邻氧化态 |
| 5 | 双峰关系超出文献范围 | 高 | 1/2 分量常受背景、重叠和 Coster–Kronig 效应影响；超出文献范围时更可能是背景或重叠的问题，而不是物理 |
| 6 | 化合物不对称 | 高 | 多重分裂或未分辨的成分会让化合物峰看起来不对称；但拖尾很容易把相邻化学态的面积吃掉 |
| 7 | 峰位范围 | 最高 | 峰位放开后，化学态可能互相交换位置；只在能量校正可靠时使用 |

- **放宽一级 ▸**：只放开下一级并重新拟合（含 3 组随机起点），给出 χ²ᵣ 与 BIC 的变化、建议、各化学态比例的变化和新出现的警告。BIC 已计入多出的参数个数：
  - BIC 下降 >10、没有新的物理问题、比例变化 ≤10 个百分点 → **建议保留**；
  - BIC 下降 >10 但比例变化 >10 个百分点，或出现“不在文献范围”“背景高于数据” → **请复核**（结果对这项约束敏感）；
  - BIC 下降 ≤10 或上升 → **建议撤销**（残差的改善不足以支撑多出的参数）。
- **撤销**：退回上一级（逐级可退）。不适用的级别（如已是自定义点背景）自动跳过。
- **自动**：只在低、中风险的前 4 级中逐级尝试，按上面的规则保留或撤回，最后给出汇总；第 5–7 级（双峰超出文献范围、化合物不对称、峰位）只能手动逐级放开。
- 一键拟合会把放宽状态重置为第 0 级。
- **验证**（已知答案的模拟谱，每类 5 次；模拟谱的 L% 为 20–30%，与默认的 30% 不完全一致）：

| 场景 | 化学态比例误差：默认约束（平均 / 最大） | 自动放宽后 | 主要保留的级别 |
|---|---|---|---|
| Co2p（Co⁰+Co²⁺+卫星） | 5.0% / 8.4% | 4.0% / 5.4% | L%（5/5） |
| Cr2p 含 Cr⁶⁺ | 7.2% / 9.0% | 3.9% / 6.5% | L%（5/5） |
| C1s 含碳化物 | 3.6% / 6.9% | 1.8% / 3.7% | FWHM 范围（4/5） |
| Cu2p 含 Cu²⁺ | 3.8% / 5.6% | 4.2% / 5.6% | L%（2/5） |
| Cr2p | 1.6% / 2.4% | 2.6% / 4.8% | L%（5/5） |
| Al2p | 2.7% / 10.7% | 2.8% / 10.7% | 几乎全部撤回 |

  平均误差 4.0% → 3.2%；改善明显的是模型约束与真实线形不一致的情况（L%、FWHM），没有出现大幅变差的情况。
- 报告时注明放开了哪些约束；比例变化很大的级别说明该结果对约束敏感，应在文中给出范围。

### 5.3 准确度的含义与局限
- 除 Fe 外，模拟谱的峰形与模型一致，因此 5.1 是**算法本身**的误差；真实谱还受峰形近似（多重分裂、损失结构）影响。Fe 的模拟谱刻意使用与模型不同的线形，更接近真实情况。
- **物理上不可区分的情况**，程序给出范围或提示，而不是单一数字：Co²⁺（金属损失结构 vs 卫星）、Cu⁰ vs Cu₂O、Cr(OH)₃ vs Cr₂O₃、Al(OH)₃ vs Al₂O₃、Co³⁺ vs Co²⁺。
- **Fe2p**：主物相 45/48 正确；错判集中在卫星很弱的 Fe₃O₄（被认成 Fe₂O₃ 或 FeO）——这正是 Fe2p 本身最难区分的情况，请结合卫星特征（4 节复核清单）与其他手段（如 Fe L 边、XRD、穆斯堡尔谱）。程序**无法确认少量混合**（如 Fe₂O₃ 中含 ≤20% Fe₃O₄），报告给出 Fe²⁺ 范围（混合样品中 4/8 的真值落在范围内）；Fe⁰ + Fe₃O₄ 时金属 Fe⁰ 比例偏高约 10–17%（磁铁矿的 Fe²⁺ 低 BE 肩峰与金属拖尾重叠）。
- **Co2p 的金属线形**：三个样品的 Co“Co²⁺”比例都是 47–49%，与它们的实际氧化程度无关（Sample1 为全金属；Sample3 的 Al 已 100% 氧化、Cr 70% 氧化）。真实的氧化不会在不同样品中恰好相同，这说明这部分强度属于该合金中金属 Co 的线形（强的高 BE 拖尾 / 损失结构），而不是 Co²⁺。在没有同一谱仪上测得的纯金属 Co 参考谱之前，Co²⁺ 比例只能作为上限；已知为金属态时用“仅金属”。
- **金属与氧化物的歧义**：金属峰拖尾的长度会直接影响氧化态比例。用户确认为全金属态的 Sample1：Cr2p 用长拖尾的纯金属模型比“Cr⁰ + Cr³⁺”更好（ΔBIC −64，默认结果 Cr³⁺ 19% 应视为 0–19%）；Al2p 的 Al³⁺ 位置与 Cu3p、Cr3s 重叠，纯金属 + Cu3p 也能解释；Co2p 在 780–790 eV 的宽结构：放宽 Fe/Co/Ni 金属 2p1/2 的文献范围、允许长拖尾后，仅金属模型与默认模型的差距从 ΔBIC +391 缩小到 +86，结合下一条（不同样品中 Co“氧化”比例恒定），更可能是金属线形。
- 内置详细模型目前覆盖 7 种轨道（Al2p、Co2p、Cr2p、Cu2p、Fe2p、O1s、C1s）；其他轨道用通用模型，需人工复核。

- Ni2p：金属比例基本正确，但 NiO 的多重分裂肩峰（+1.5 eV）与 Ni(OH)₂ 位置重合，两者的区分不可靠——需要 Biesinger 的多重分裂包络，v1.1 未做。
- Fe2p：同一组模拟谱上 v1.0 与 v1.1 对比（Fe₃O₄、Fe+Fe₃O₄、Fe+Fe₂O₃ 各 4 次），主物相正确 7/12 → 9/12（Fe+Fe₃O₄ 1/4 → 3/4，来自氧化物双峰间距下限 13.4 → 13.3），其余结果相同。
- 真实数据回归（Sample1–3 共 15 条谱，v1.0 与 v1.1 对比）：12 条完全相同；Cr2p 3 条相差 ≤ 0.3 个百分点（Cr³⁺ 双峰间距下限 9.5 → 9.4）。开发中曾出现 Sample3 Al2p 的残差峰被 NIST 命名为 AlF₃ 并计入定量 → 改为残差峰只用与样品元素相符的化合物命名（样品没有 F 时不会出现 AlF₃），回归消除。
